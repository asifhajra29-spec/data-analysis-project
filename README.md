# 📊 Retail Sales Analysis

A beginner-friendly Business Analytics project using Python to explore retail sales, profit, regional performance, product categories, and discounts.

> **Dataset note:** This repository uses a retail-style practice dataset created for portfolio learning. It is not presented as real company data.

## 🎯 Objective

Turn transaction data into clear business insights through data cleaning, exploratory data analysis (EDA), descriptive statistics, visualization, and business interpretation.

## ❓ Business Questions

- Which category generates the most sales and profit?
- Which region contributes the most sales?
- How does sales performance change over time?
- What relationship can be observed between discounts and profit?

## 🛠️ Tools & Skills

- Python
- Pandas
- Matplotlib
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Descriptive Statistics
- Data Visualization
- Business Insight Generation

## 📁 Project Structure

```text
├── data/
│   └── sales_data.csv
├── analysis.ipynb       # Exploratory analysis notebook
├── analysis.py          # Reusable analysis script
├── requirements.txt     # Python dependencies
└── README.md
```

## 🔍 Analysis Workflow

1. Load and inspect the dataset
2. Check data quality and missing values
3. Calculate sales, profit, profit margin, and average order value
4. Compare categories and regions
5. Analyze monthly sales trends
6. Explore discount vs. profit relationships
7. Translate findings into business meaning

## 🚀 Run the Project

```bash
pip install -r requirements.txt
python analysis.py
```

Or open `analysis.ipynb` in Jupyter Notebook.

The Python script saves analysis charts to an `outputs/` folder when it is run locally.
